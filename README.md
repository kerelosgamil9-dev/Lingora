# Lingora

تطبيق موبايل لتعلم الإنجليزية وتأسيس المبتدئين من الصفر — Pure Kivy + SQLite (بدون KivyMD).

## الملفات
| الملف | الوظيفة |
|---|---|
| `main.py` | نقطة التشغيل: النافذة، القائمة الجانبية، التنقل، الخطوط |
| `database.py` | قاعدة SQLite: المجلدات، الكلمات، التقدم، الستريك، النسخ الاحتياطي |
| `data_bank.py` | بنك الكلمات والجمل الجاهز (8 مستويات) |
| `screens.py` | كل الشاشات (الرئيسية، المجلدات، المستويات، التحديات، الإعدادات) |
| `games.py` | الألعاب: بطاقات، اختيار من متعدد، عكسي، توصيل، إملاء، سرعة، بقاء |
| `widgets.py` | مكونات الواجهة (أزرار، أيقونات، شعلة الستريك، فواصل، نوافذ، درج) |
| `rtl.py` | تشكيل الحروف العربية وضبط الاتجاه (بدون مكتبات خارجية) |
| `strings.py` | نصوص الواجهة بالعربية والإنجليزية |
| `theme.py` | ألوان الوضع الليلي والنهاري |
| `services.py` | النطق الصوتي (TTS)، المؤثرات، مسارات النسخ الاحتياطي |
| `fonts/` | خط يدعم العربية (DejaVu Sans) — **لازم يفضل جنب main.py** |
| `buildozer.spec` + `.github/workflows/build.yml` | بناء APK على GitHub Actions |

## التشغيل على Pydroid 3
1. انسخ المجلد كله (بما فيه `fonts`) على الموبايل.
2. ثبّت Kivy من Pip داخل Pydroid 3 (إن لم يكن موجوداً).
3. افتح `main.py` واضغط تشغيل.

## بناء APK على GitHub
ارفع المجلد كله على مستودع GitHub (فرع `main`)، وسيعمل الـ Workflow تلقائياً.
بعد انتهائه ستجد الـ APK في Actions → Artifacts → `lingora-apk`.
